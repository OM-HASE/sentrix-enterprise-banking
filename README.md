# SentriX Enterprise Banking System

A vulnerable multi-file enterprise banking system intentionally designed for autonomous debugging and runtime repair demonstrations using SentriX AI.

## Features

- Account management
- Transaction engine
- Logging subsystem
- Database subsystem
- Concurrent processing
- Runtime validation

## Runtime Failure Categories

- Division by zero
- Null pointer dereference
- Vector out-of-bounds
- Buffer overflow
- Memory leak
- Use-after-free
- Double delete
- Queue underflow
- Stack underflow
- Invalid thread access
- Invalid map dereference
- Race condition
- Infinite recursion

## Purpose

This repository demonstrates:

- Repository-aware cognitive debugging
- Runtime crash analysis
- Autonomous repair generation
- Regression-aware validation
- AI-generated pull requests
- Cross-file dependency analysis
